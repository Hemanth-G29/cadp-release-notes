  • Formula Builder UI
    1. On clicking a feature from the feature list, fields in the selected feature should be displayed, except for the current field, to prevent self-call loops.
    2. On selecting external feature fields, where() should appear in the modal.
    3. On selecting where(), the modal should automatically switch to the Feature and Fields tab.
    4. On hovering over a field, field information such as module name and feature name should be displayed.
    5. The Clear button or backspace should work as follows:
      1. First click of clear/backspace will select the token.
      2. Next click of clear/backspace will clear that token.
    6. Empty formulas should not be saved.
    7. Formulas should not be saved without validation.
  • Formula Builder – Helper Tools
    1. Cheat Sheet (? icon)
      1. Open the Cheat Sheet and verify functions are grouped by category (Lookup, Nested Lookup, Aggregation, Conditional, Math, String, Date).
      2. Search for a function and verify the list filters correctly.
      3. Click the copy icon on an example and verify it is copied to the clipboard.
      4. Press Esc and verify the modal closes.
    2. Examples
      1. Open the Examples drawer and verify 50 scenarios across all categories are listed.
      2. Filter by a category and search; verify results update.
      3. Click "Use This Pattern" and verify the formula is inserted into the editor.
    3. Test Formula (Playground)
      1. For a current-feature calculation (e.g. {number_field} * 5), open Test Formula, verify a type-aware input appears per field (number/date/true-false/text), enter values, run, and verify the correct result, type, and (where relevant) matched-record count.
      2. For a lookup formula (uses .where() / external feature fields), verify NO value-input form is shown and a "Lookup formula – test against a real record" message appears instead.
      3. For an aggregate formula (SUM/COUNT/AVG/MIN/MAX of records), verify the "Aggregate formula – test against a real record" message is shown and the form is not available.
      4. Verify the Test Formula button is disabled when the formula is empty.
    4. Template Library
      1. Open the Template Library and verify the Most Used tab lists the 20 platform built-in templates (e.g. GST, TDS, net salary, lookups, aggregations).
      2. Search and filter by category; verify results update.
      3. Click "Use This Template" and verify the formula is inserted into the editor.
      4. With a formula in the editor, click "Save current formula as template", fill title/category/description, save, and verify it appears under My Templates.
      5. Delete a saved (non built-in) template and verify it is removed. Verify built-in templates cannot be deleted.
    5. Formula Wizard
      1. Lookup mode: choose "Lookup a value", select a source feature, select the field to return, add a match condition (verify the "Right side is a field reference" option shows a dropdown of the current feature's fields), check the live preview, and Insert.
      2. Aggregate mode: choose "Aggregate records", select feature/field, optionally add one filter condition, choose the function (SUM/COUNT/AVG/MIN/MAX), and Insert.
      3. Verify the formula preview only appears after a return field is chosen, and that going Back keeps your previous selections.
      4. After inserting, hover over the tokens in the editor and verify the correct Module name and Feature name are shown for each (including the source feature for the looked-up field).
    6. Smart Validation Messages
      1. Enter an invalid formula (e.g. unknown function, missing where(), wrong argument count) and click Validate Expression; verify the error includes a helpful suggestion and an example, not just a generic message.
