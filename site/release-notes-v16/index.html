2. Release Summary

This release of CADP Workspace Version 1.0.0 (16) delivers several new capabilities alongside performance and stability improvements. Key highlights include a new OCR component for in-form text extraction, the Erudite Management knowledge module (FAQs, documentation, and tutorial videos), a set of Formula Builder helper tools (cheat sheet, examples, test playground, template library, and wizard), and updated password-based login with system-default workspace routing. The release also optimizes platform and feature design page loading time and includes multiple bug fixes across the platform.

3. New Features

Feature ID Feature Name Description Impact
– OCR Component A new OCR component is available in the Feature Builder. It allows users to upload an image or document and extract text directly within a feature form. General text extraction works out of the box. Field-level extraction (structured data extraction into specific fields) requires a paid API access token for OpenAI or Gemini, configured in the platform integrations settings. Feature designers and end users handling image or document-based data entry
– Password-Based Login – Workspace Routing & System Default Fallback Password-based login now uses password group logic to route users to the right workspace, with an updated fallback so most users land on the dashboard without a workspace popup:
  • Single workspace – the user is logged in directly; no popup.
  • Multiple workspaces, user default saved – the saved default (from User Preferences → Preferred Workspace) is used and the password verified against it; logged in directly.
  • Multiple workspaces, no user default, system default configured (new behaviour) – CADP now automatically looks up the company's system-level default workspace, confirms the user is a member, verifies the password against it, and logs the user in directly with no popup. Previously the Select Workspace popup was shown even when a system default existed.
  • Multiple workspaces, no default anywhere – the Select Workspace popup is shown; the chosen workspace applies to that session only.
  • Unique password per workspace – the entered password itself selects the matching workspace and logs the user in directly.
  • No role assigned – login is denied with "Role is not assigned to this user. Please contact your Administrator for Access."
Web and mobile defaults are stored separately and filtered by client type. 		All users logging in with email/mobile and password; administrators configuring a company-wide default workspace
– Erudite Management A new knowledge management module available to top-level administrators (Cavin Admin). Admins can create and publish FAQs (with question, answer, and category), upload Documentation (PDF/DOC, max 5 MB), and upload Tutorial Videos (MP4/MOV/MKV, max 50 MB) about the organization, workspaces, and platform usage. Each item supports categorization (Account, Billing, General, Technical) and can be optionally pinned to the dashboard for quick access. End users can browse FAQs, read documentation, and watch tutorial videos through a self-service knowledge portal. Note: Erudite Management must be enabled in Role Management before use. Top-level administrators managing platform knowledge content; all platform users consuming FAQs, documentation, and tutorial videos
– Formula Builder – Helper Tools A set of in-editor tools in the Formula Expression Builder that help business users write and verify formulas without learning the formula syntax. All tools are available from the formula editor toolbar:
  • Cheat Sheet (? icon) – a searchable reference of 30+ functions grouped by category (Lookup, Nested Lookup, Aggregation, Conditional, Math, String, Date). Each entry shows the syntax, an example, and a description; the example can be copied to the clipboard. No data is changed.
  • Examples – a side drawer with 50 ready-made business scenarios (Lookup, Aggregation, Conditional, Date, String, Tax, Payroll, Inventory, Finance). Clicking a scenario inserts its formula pattern into the editor. Placeholder field names must then be replaced with real fields from the Features tab.
  • Test Formula (Playground) – runs the current formula and shows the result, type, matched-record count, and evaluation path. For pure calculation formulas that use only the current feature's own fields, the user enters sample values (inputs adapt to each field's type – number, date, true/false, text) and gets a real result. Formulas that look up values from another feature, reference external fields, or aggregate child records cannot be tested with typed values – they show clear guidance to test against a real record and to use Validate Expression for syntax checking.
  • Template Library – two tabs: Most Used shows 20 platform built-in formula templates (e.g. GST, TDS, net salary, overtime, single/multi-condition lookups, nested lookups, aggregations, date calculations, currency conversion) and My Templates shows formulas saved by the workspace. Supports search, category filters, "Use This Template" (inserts the formula), and "Save current formula as template".
  • Formula Wizard – a no-code, step-by-step builder. The user chooses a mode (Lookup a value or Aggregate records), selects the source feature, the field to return/aggregate, match conditions (with the current feature's fields available as a dropdown), and – for aggregates – the function (SUM/COUNT/AVG/MIN/MAX). A live preview shows the formula being built, and "Insert Formula" places it in the editor.
  • Smart Validation Messages – validation errors now include a suggestion and an example alongside the message, instead of a generic "invalid expression".
Note: AI-based formula generation ("Generate a formula using AI…") is not yet available in this build. 		Business users (BA, Finance, HR, Operations) and feature designers building formulas in the Feature Builder

8. Known Issues

Issue ID Description Workaround
Role Management Change Effect Because some menu structures have changed, certain features may return a 403 status code. To resolve this, edit the role, select the platform feature, and save the role again.
Scheduler with Workflow Not Working Use the conventional feature-wise approach wherever workflow scheduling is required.
Formula Builder UI – Field Insertion Through Typing This works in current fields. For external feature fields, it won't work, as there could be fields with same names from multiple features
Formula Builder – AI-Based Formula Writing/Editing Not Implemented Use manual formula entry instead.
364 Organization Details → Basic Info: Website URL accepts invalid URL formats without validation. Expected: Validate the URL format and show an error message for invalid values, such as www.example or example@123.www.example

Builder Tool Not Available on Mobile Web The builder tool is not supported on mobile web. This is implemented as expected — builder functionality is restricted to desktop browsers by design. It should be available on Tab though.
Mobile – Formula Field Not Working in Tables & Charts Formula fields are not evaluated correctly when used inside Tables and Charts on mobile. This is under review.
