2. Release Summary

This release of CADP Workspace Version 1.0.0 (15) focuses on platform performance and stability. Key highlights include optimized platform loading time, optimized feature design page loading time, and multiple bug fixes across the platform.

3. New Features

Feature ID Feature Name Description Impact
– Mobile Native mobile application and mobile web are available in this build. Users can access CADP Workspace on mobile devices through both the app and the browser. Mobile app and mobile web users
– Workflow – OCR Node A new OCR (Optical Character Recognition) node is available in the Workflow builder. When added to a workflow, it extracts text from images or document files and makes the extracted content available as output variables for downstream nodes. Workflow designers and users processing image or document data
– OCR Component A new OCR component is available in the Feature Builder. It allows users to upload an image or document and extract text directly within a feature form. General text extraction works out of the box. Field-level extraction (structured data extraction into specific fields) requires a paid API access token for OpenAI or Gemini, configured in the platform integrations settings. Feature designers and end users handling image or document-based data entry
– Erudite Management A new knowledge management module available to top-level administrators (Cavin Admin). Admins can create and publish FAQs (with question, answer, and category), upload Documentation (PDF/DOC, max 5 MB), and upload Tutorial Videos (MP4/MOV/MKV, max 50 MB) about the organization, workspaces, and platform usage. Each item supports categorization (Account, Billing, General, Technical) and can be optionally pinned to the dashboard for quick access. End users can browse FAQs, read documentation, and watch tutorial videos through a self-service knowledge portal. Note: Erudite Management must be enabled in Role Management before use. Top-level administrators managing platform knowledge content; all platform users consuming FAQs, documentation, and tutorial videos

8. Known Issues

Issue ID Description Workaround
Role Management Change Effect Because some menu structures have changed, certain features may return a 403 status code. To resolve this, edit the role, select the platform feature, and save the role again.
Scheduler with Integration Not Working Use manual integrations wherever scheduled integration is required.
Scheduler with Workflow Not Working Use the conventional feature-wise approach wherever workflow scheduling is required.
Formula Builder UI – Field Insertion Through Typing This works in current fields. For external feature fields, it won't work, as there could be fields with same names from multiple features
Formula Builder – AI-Based Formula Writing/Editing Not Implemented Use manual formula entry instead.
364 Organization Details → Basic Info: Website URL accepts invalid URL formats without validation. Expected: Validate the URL format and show an error message for invalid values, such as www.example or example@123.www.example
Builder Tool Not Available on Mobile Web The builder tool is not supported on mobile web. This is implemented as expected — builder functionality is restricted to desktop browsers by design.
Mobile – SSO Login: Error Case Not Working SSO login error scenarios (invalid credentials, expired tokens, etc.) do not display correct error messages on mobile. This is under review.
Mobile – Formula Field Not Working in Tables & Charts Formula fields are not evaluated correctly when used inside Tables and Charts on mobile. This is under review.
