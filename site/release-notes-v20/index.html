2. Release Summary

This release of CADP Workspace Version 1.0.0 (20) delivers 189 bug fixes, 26 new features, and 23 enhancements across the platform. Highlights include Feature Design Lock (concurrent design safety), Stepper – Role-Based Access per Step, and Workflow – Approval Gate Node. It also includes a required configuration change (see Configuration Changes) and API changes (see API Changes). Refer to the Known Issues section for current limitations.

3. New Features

Feature IDFeature NameDescriptionImpact
Feature Design Lock (concurrent design safety)Only one user can open a feature in the Builder at a time. A second designer opening the same feature sees it read-only with a "being designed by <user>" message. The lock is released when the first designer leaves, or taken over after about 90 seconds of inactivity.Prevents two designers overwriting each other's changes.
Stepper – Role-Based Access per StepEach stepper step can be restricted to specific roles ("Who can access this step"). A later-step role sees earlier steps as read-only for context. Each step has an override: Stepper default / Show disabled / Hide / Editable.Supports approval-chain style forms (requester → reviewer → approver).
Workflow – Approval Gate NodeNew workflow node that maps the buttons of a linked feature's stepper to step routing, so a button click moves the record to the configured step.Stepper approvals can be driven from the Workflow Builder.
Workflow – Approval Request "By Field" ApproverApproval Request / Chat Approval nodes gain a third approver mode, "By field": the approver is taken from a field on the record, alongside Specific users/roles and Reporting hierarchy.Dynamic approvers without a separate workflow per approver.
Workflow – Trigger on Bulk Import (onUpload)A workflow can now be bound to the onUpload trigger of a feature. Importing records (Import modal, any import mode) fires the workflow once per batch, and Upsert / Create Record nodes process every imported row. Large imports are processed in chunks.Imports can update related masters (e.g. stock) automatically.
Workflow – Filter, Match Combine and Table Row Mapping on Record NodesUpsert / Update / Create Record nodes get a Filter section (AND/OR conditions) that decides whether the node runs. Upsert adds a Match Combine AND/OR toggle when two or more Match Key fields are tagged, and Table Row Mapping can append a new table row or find and update an existing row by Match Key.More precise record updates from workflows.
Scheduler – DB-Sync Schedule ModeThe Task modal's Schedule Mode now offers DB-Sync (next to Expression Builder / Integrations / Workflow). Pick a Module and Feature to schedule its Database Sync.Database Sync can run on a schedule.
Database Sync – Query Variables and Group ByThe query builder's Feature fields reference picker can add multiple reference rows and feed the picked values into the query as named variables (including IN-lists). Field mapping's Group By merges source rows that share the grouped column into one record.Parameterised sync queries and line-item grouping.
External Database – Amazon RedshiftAmazon Redshift is available as a database engine for integrations, alongside MySQL/MariaDB/PostgreSQL/MS SQL/Oracle.
Role Management – Data Sources TabRole Edit has a new Data Sources tab to choose which external data sources a role may use and to add row rules (e.g. Region = <value>, picked from a value list). Dashboards and explorers only return rows allowed by the rule.Row-level access control on external databases.
Dashboard – Filters, Refresh and Period ComparisonThe Date and Filters buttons now work on dashboards whose widgets use an external database. Each dashboard tab has a real hard refresh. KPI cards gain a "Same period last year" comparison. Fourteen new financial and calendar period presets (e.g. Q1–Q4, H1/H2, FY, last year) are available in all filter surfaces.
Date / Datetime Picker – Default DateAdvanced → Datepicker / Datetimepicker (and date columns in tables) has a Default Date block, so a field can open with a date already selected.
Dropdown – "With States" (State Transitions)A manual-options dropdown can enable With States and define State Transitions, so the options offered depend on the field's current value.Status fields that only allow valid next states.
Radio Button – Show as ChipsRadio / radio-group fields have a "Show as" option: Default (radio list) or Chips (selectable pills).
Formula – sortBy(), limit(), DATE_DIFF weeks, Textarea displayThe formula builder offers sortBy() and limit() after a .where() lookup to pick one record when several match. DATE_DIFF supports "weeks" (it previously returned days). Formula fields gain a third Show As mode, Textarea.
Table – Show Column Label on HoverTable Settings → Column Header has a "Show Column Label on Hover" toggle for data, report and transaction tables.
Listing – Group Cards by Field with Variant ChipsListing Data Source can group records by any field and show attribute chips (e.g. size, shape). Only combinations that exist can be selected (others are disabled), card fields show the selected variant's values, and the cart saves the chosen SKU. "Groups to show" and Variant Fields are configurable.
Listing – Offers, Pricing and StockOffer values (badge, savings) can be mapped into listing card fields, with a per-listing offer Behaviour section. Pricing supports batch-wise prices, per-UOM prices and price revisions (e.g. increase by %). An out-of-stock item can be replaced by an in-stock equivalent (Transaction Settings → Replace Out-of-Stock Products), and stock shows a UOM breakdown.Configured through Transaction Settings.
Workspace Hierarchy EngineSales / Geo / Product hierarchies can be configured per workspace. The Product mapping can use the Product Level Master to show level names next to level codes.
Login – Login Param, Login Identifiers and Password PolicyUsers can log in with the value of a chosen workspace feature field (Login Param, e.g. Employee ID). A tenant setting LOGIN_IDENTIFIERS restricts login to User ID / Mobile / Email / Any, with a specific error message. Password history and maximum password age are enforced, and change-password-at-login follows the tenant's setting.
Auto Gen ID – Financial Year [YYYY]The Auto Gen ID field's Advanced → Financial Year dropdown offers Financial Year[YYYY] (e.g. PAY-2026-0001). Workflow Create / Upsert Record nodes support it too.
Chat – Calling ImprovementsRefreshing the browser during a call reconnects instead of ending the call for everyone. Group/community calls respect a call permission and show a "call in progress" banner.
Data Management – Backup Count and Safety BackupsThe Backup page's Total Backups card shows the real total. Automatic pre-restore backups carry a purple "Safety" badge. "Go to Schedules" opens the Scheduler tab and the create form when there are no schedules.
Erudite Documents – AI Search StatusDocumentation cards show an AI-search status badge (AI ready / Indexing… / PDF only / Not indexed + Retry) that updates on its own. Uploading a non-PDF shows a warning.
Release Notes (in-app) – Scan Workspace and TemplatesScan Workspace lets you pick modules, features and workflows before scanning, and clicking a detected change opens its field-level version history. New default templates, including QA Build Release Notes and Complete Release Outline, are in Browse Templates. The Release Notes card is replaced by a Documentation Hub (Release Note Generator / User Manual Generator / SOP Management), shown per role permission.
Workflow – OCR Extract Tesseract ProviderThe OCR Extract node has an OCR Provider option, Tesseract (runs locally, no API key).

Build with AI runs on the server, so a page reload no longer abandons a build. ImportThe Import button is in the modal footer. File type and size are checked up front, and the size limit is now 100 MB. Every failure in a row is listed, not just the first. The sample template's transaction-table sheet offers the referred feature's values, and create-mode imports are much faster.Large files can be imported. Users see every problem with a row in one go and can fix the file in one pass. Imports finish much faster.

The OCR Scanner component has the Duplicate / Delete toolbar.Designers keep their place on long forms and card menus behave predictably, which makes form design faster and less error-prone.
BuilderThe Publish button and the feature card / Transaction Management header now show the same publish status (e.g. for cloned features).Everyone sees the same, correct publish status, and a feature that is ready can actually be published.
Listing / CarouselData Source Module / Feature / grouping field pickers are searchable dropdowns and now list nested features.Features are quicker to find in large workspaces, and nested features are no longer missing from the list.
DashboardThe Financial Year dropdown lists the years the data actually covers. The dashboard runtime is responsive (2 widgets per row on tablet, 1 on mobile), and data tables use the chart-tile style.Users only see financial years that have data. Dashboards are usable on tablets and phones, and tables look consistent with charts.

Deleting one row no longer clears the others. Formula columns can be overridden Excel-style, and label-mode cells are click-to-edit.Tables show the component the designer configured. Read-only data stays protected, and deleting one row can't wipe out the other rows' data.
Formula BuilderIt opens and searches fields without freezing. The Cheat Sheet can copy the syntax line. Tab headers are no longer offered as fields. The Aggregate Wizard builds COUNT_RECORDS correctly. The table column Decimals setting is honoured. Filter conditions support {Field} == null / != null. The Template Library search returns results. Label-mode values follow the field's text colour and gain a Value Sign option.Formulas are faster and easier to build, and more formulas give correct results without workarounds.
Formula BuilderSquaring a negative value (e.g. {x} ^ 2 with x = -5) returns a positive result, and table lookups are faster.Calculations match standard maths and Excel behaviour, and tables with lookups load faster.
Data GridSubmitting a data-grid config field saves one record with child rows instead of one duplicate record per grid row.No duplicated header records. Each submission is one clean record, which keeps reports and record counts accurate.
Workflow – Upsert / Update / Create RecordField Mappings use a two-column Target / Source layout, and the panel is resizable. Auto-Map is a toggle. The Update operation offers Set / + / - / * and is shown only for number fields. Tagging a Match Key that isn't a Unique Key shows a warning with a "map on both sides" note.Field mappings are easier to read and set up, and the new warnings help avoid mistakes such as matching on a non-unique field.
Workflow – AIAI workflow generation shows a clear message when the AI cannot read workspace data.Users understand why AI workflow generation failed instead of seeing a technical error.
Role ManagementSaved role permissions apply immediately without a page reload. Menu Access Control has a single scrollbar, and its heading stays in place.Permission changes apply straight away without a re-login or page reload, and large permission trees are easier to navigate.
Erudite ManagementAdd / Edit / Delete buttons on Documentation, FAQs and Tutorial Videos follow the role's permissions.Users only see actions they are allowed to perform, so there are no surprise permission errors.
Credential ManagerUsers added through bulk import now get RBAC logins, and newly created users trigger the user-creation email.Users created through bulk import can log in straight away and receive their login email, the same as users created one by one.
Print TemplatesThe New Print Template modal has Mode and Paper Size dropdowns (A3 / A4 / A5 / Letter / Custom, plus thermal receipt sizes). A template can be renamed from the editor header.Templates can be set up for any paper size, including thermal receipt printers, and renamed without leaving the editor.
Transaction PreviewThe ⋮ menu (Import / Hold / Recall) shows only for transaction features, and the duplicate "Back to Builder" button is removed.A cleaner toolbar that only shows actions relevant to the feature type.
Footer / Number Format / TemplatesThe footer shows the logo and brand name together. The phone format's Default Country dropdown shows readable flags and dial codes. Templates can use the organization.loginUrl variable.Branding and phone numbers display correctly, and emails can link users straight to their login page.
Performance / NetworkFewer and smaller requests. The feature list response no longer duplicates field data. The formula picker makes two requests (feature list + selected feature's fields). Field lists a user can't read are not re-requested for 60 s. Formula batch / evaluate-table payloads carry only what each formula needs. Table formula lookups fetch only matching records instead of scanning the referenced feature. One fewer metadata request per local formula.Pages and the formula builder load faster, with less data sent over the network.
Performance / CachingA row rule saved on a role takes effect immediately (it could take up to 24 hours because of a stale cache). Database Sync Test Query previews are capped to a small number of rows when the query has no LIMIT. Create-mode imports insert a chunk at once instead of row by row.Access rule changes apply immediately. Test queries return quickly, and big imports finish faster.
Security (Network tab)Database passwords and payment secret keys no longer appear in any browser response. External-DB widgets send only the data source id.Sensitive credentials can no longer be seen in the browser, which reduces the risk of data leaks.
