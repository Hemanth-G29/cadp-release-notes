2. Release Summary

This release of CADP Workspace Version 1.0.0 (21) delivers 31 bug fixes, 19 new features, and 16 enhancements across the platform. Highlights include Login – Multi-Factor Authentication (MFA), Workspace Switch – Password + OTP, and Session Params (Workspace Management → Session Params). It also includes a required configuration change (see Configuration Changes) and API changes (see API Changes). Refer to the Known Issues section for current limitations.

3. New Features

Feature IDFeature NameDescriptionImpact
Login – Multi-Factor Authentication (MFA)Organisation Details (Metadata Console → Organisation) has a new "Multi-Factor Authentication (MFA)" toggle. When it is on, a correct email/mobile + password login shows a "Verify it's you" step: choose Email or Mobile (SMS) — each shown partly hidden — click Send OTP, enter the 6-digit code and click Verify & Sign In. Resend is available after 30 seconds; the code is valid for 5 minutes and 5 wrong codes end the attempt (log in again). Applies to web and mobile. SSO logins are not asked for an OTP.Stronger sign-in security, switched on per organisation.
Workspace Switch – Password + OTPWhen the organisation's auth policy is "Workspace" and MFA is on, switching workspace from the header asks for the target workspace's password and then a one-time code (Email or Mobile). With the tenant variable ALLOW_ADMIN_SWITCH_PASSWORD = true, Administrators must do the same; when false (default) Administrators switch as before.
Session Params (Workspace Management → Session Params)A new Workspace Management tile where an admin picks the Login Param feature and the values to capture when a user logs in — from a field, a lookup, a linked feature, or a matching record in another feature — with a live preview for a sample login value. "Use session params in other features" maps a session key to a field of any feature (Equals / Starts with / Contains), so users only see that feature's matching records. Role → Data Access Control conditions can also use a session key (listed as sessionParams.<key>), and match both plain and lookup fields.Record-level visibility per user (e.g. a sub-distributor sees only their distributor's data) without one rule per role.
Unique CombinationsFeature Information (below Corner Style) lets you define one or more Unique Combinations — a set of fields joined by AND. A record is rejected only when every field of a combination matches an existing record, with the message "Duplicate combination for fields … This combination must be unique."Business keys such as Code + Branch + Year can be kept unique.
Table View – Column Filter and Column SearchTransaction Settings has new Column Filter and Column Search cards. Each ticked field gets a funnel (and/or 🔍) button in its column header on the landing page's table view. The funnel offers a pick list (with value counts) for dropdown-type fields, text contains, number range or date range; active filters show as removable chips with "Clear column filters", are remembered per browser, and are honoured by Export. Fields that cannot be filtered are listed disabled with the reason.
Formula – Evaluation LogicA new Evaluation Logic card in Transaction Settings (shown only on features with formulas) chooses whether formulas recalculate when a page opens in Create, Edit or View mode (defaults: Create on, Edit off, View off). A fourth option, "Wait for all referenced fields", keeps a formula blank until every field it reads has a value (zero counts as a value).Saved figures stay as saved, and formulas don't show answers calculated from blank fields.
Print – Download as WordRecords whose print template can be shown in Word get a Download Word action beside Download PDF (⋮ actions in list, grid, table and card views, and on Kanban cards). It uses the same published template and record data as the PDF.
Print – Row Filter and Default Font SizeA print report table can print only matching rows (Row Filter: column, condition, value) — the canvas preview applies the same rule. The template settings modal offers the designer's 8 fonts and a new Default Font Size (8–72 px); new templates default to Arial 12 px, and the defaults also apply in the designer canvas.Documents such as a sales-return credit note list only the relevant lines.
Open Document on Record ClickView Settings (Transaction Settings → Views & Fields) has a per-view option "Open document when a record is clicked" for Grid, List, Table, Kanban and Card, with What opens: Published document else print preview (default), Published document only, or Print preview always.
Publish to EruditeNew Workflow node "Publish to Erudite" publishes an approved record's print document to Erudite Management (opens, is searchable by AI and is deleted like a manual upload). Transaction Settings → Publish to Erudite decides per feature: Publish automatically / Always ask / Don't publish. With Always ask, the record shows an amber "Awaiting publish" chip and users with modify permission get a publish button in the record actions.Approved SOP-style records reach Erudite without a manual upload.
Workflow – In-App Notification NodeNew Communication node that sends a bell/inbox notification to selected users or roles, with custom title/body (@mentions) or a published In-App template, plus type, priority, display style, expiry and dismissible settings. "When Clicked" can open a chosen feature (list, new entry or the triggering record), a custom URL, or do nothing.
Workflow – Line-Item (Table Row) ProcessingCreate Record has a Table Row Mapping section (writes all source table rows into ONE created record's Data Table) and a Records Field (creates one record per item). Switch/Case can route each table row by its own value (Match Table Rows). Update Record updates one record per row when its match value is a table column. Upsert can expand nested child rows ("Expand nested line items") and has a new "Update only" option that never creates a record.Header + line-item flows (Order → Invoice, Loadout → Delivery → Inventory) work without one record per product row by mistake.
Task Scheduler – Task Groups, Today Conditions and Record ActionsThe Task Group tab lists the workspace's groups (name, description, task count) with + New Task Group, Edit and Delete. Date conditions in the Task modal can use Specific date / Today / Now with a ± days offset (e.g. Expiry Date ≤ Today). Tasks can run Record Actions (Update / Upsert records) on schedule, and a new Schedule Query Builder task type targets up to 2 features.Expiry-style automation (e.g. move expired stock to an Unsellable line) without code.
Inventory – Committed and On-Route StockStock held by confirmed orders (Committed) and dispatched orders (On Route) is now deducted from available stock when those quantity fields are wired in the inventory settings.Available stock no longer double-counts stock already promised or in transit.
Listing – Formulas from Any Feature and Simple Details LayoutListing card values are authored in Display Fields → + Add Formula, and a formula can use fields from any feature (e.g. a margin % looked up by Product Code). Listing → Details Page → Default template has a new Layout option: Standard or Simple (white page, thumbnails beside the image, lighter info column).
Table Columns – Maximum Limit, Read-only and Set-value ConditionsNumeric table columns can set "Maximum from another column" (optionally summing sibling unit columns with conversion factors) and either show an error or reject the edit, optionally opening a Modal. A column's Read-only and Set-value conditions, and a feature-sourced dropdown column's Advanced Filters, are now applied at runtime.e.g. Sales Return can no longer accept more returned stock than was invoiced.
Label – Insert a Field with @In a Label's Content Text, typing @ opens a field picker (table columns included) that inserts the field as a {Field Name} token; Enter/Tab insert, arrows move, Escape closes.
Auto-populate ChainsA field that fills from another field now also works when that parent was itself auto-filled — e.g. on Sales Return, picking an invoice fills Distributor, which then fills the distributor's address, city, state and GSTIN. Clearing the invoice clears the whole chain.
Chat – Audio Call Layout and Meeting Task ListAudio calls open in the dark gallery layout automatically, with a floating toolbar and no white bars. Meetings have a checkable task list (hosts add/remove, any participant ticks), and extra participant thumbnails collapse into an overflow cluster.

4. Enhancements / Improvements

Enhancement IDModuleDescriptionBenefit
Login – LockoutLogin uses the tenant's current MAX_LOGIN_ATTEMPTS. When the limit is reached the user is told the account is locked and to try again in N minute(s), and an automatic lock lasts the tenant's RESET_UNLOCK_EVERY (unlocking is checked every minute).Users know why they cannot log in and when to retry, and the lock matches what the tenant configured.
Login – Password Reset and ChangeForgot password gives the same response whether or not the account exists, an OTP is invalidated after 5 wrong tries, and OTPs are no longer written to logs. The reset confirmation email now carries the user's details. With LOGIN TIME CHANGE PASSWORD on, the change-password screen keeps appearing until the password is actually changed.Accounts can't be discovered or brute-forced through password reset, and the forced change can't be skipped.
Security – File LinksUploaded file links (logos, portal and feature files) now carry their own read-only access for that one file instead of a key to the whole storage container.A leaked file link can no longer be used to read, change or delete other files.
Credential ManagerUsers created by Credential Manager get workspace roles from the record's Roles field, or a feature-level default. Administrator and inactive roles are never assigned this way.No more assigning roles one by one in User Management after users are created.
DashboardSetting a dashboard's Status to Inactive (Templates Library → Dashboard → Edit) now hides it from every user's landing page and dashboard switcher. Admins can still open, edit and re-activate it.A dashboard can be taken out of use without deleting it.
Landing Page – Badge ColorsA field with Badge Colors applied (Transaction Settings → Badge Colors) is always shown as a coloured column on the landing page for every user, even if the field is Hidden or role-restricted on the form.Status colours stay visible in the list for everyone.
Data Tables – Child RowsData Tables with nested Child Rows keep each row's child rows when the record is saved and reopened, including tables filled by workflows.Invoice rows keep their product lines (e.g. Loadout → Delivery) instead of losing them on save.
Transaction Table – PerformancePicking a product and adding it to a transaction table returns in about 1.7 seconds instead of stalling for up to 30 seconds; lookup formula columns fill a moment later. Listings with simple projection formulas no longer load entire features first.Faster order entry and listings; visible as much shorter requests in the Network tab.
Formula Columns – Show AsFormula table columns follow their Show As setting: Label shows the formatted value and switches to the editor on click, Text area gives a multi-line cell (now for every column type), Input is unchanged.Columns look and behave the way the designer configured them.
Builder – Duplicate TableDuplicating a table gives every column in the copy a fresh identity and rebinds the copy's own formulas and conditions to it.Formulas and rules on the copy no longer act on the original table.
Field PickersField pickers (e.g. Template Library variables) now list fields that sit inside role-restricted stepper steps.Stepper-based features show all their fields when building templates.
Print TemplatesEach Printing card has a ⚙ Template settings button to edit name, description, category, mode, paper size, orientation, font and language after creation. Double-clicking a card opens it in design mode. Selected Modules and Features are kept when a template is reopened, and both pickers are searchable. Saved templates print blocks exactly where they are drawn.Templates are easier to manage, and printouts match the design.
Print – PDF SpeedPrint View / Download reuse an already generated PDF when nothing in the record or template has changed, instead of rendering it again.Faster PDF view/download and no duplicate stored documents.
Workflow – Linked FeaturesThe Linked Features picker on Create, Upsert, Communication and Utility nodes browses modules independently of the node's target module.Picking a feature to @-mention no longer changes which feature the node writes to.
Workflow – Bulk ImportWhen a bulk import uploads header records that each carry line items, If Condition and Upsert nodes process each line (header + line fields). Upsert also reads table rows added after the workflow started (e.g. at a later approval step).Imports and approvals create/update one record per line as expected.
Approvals – NotificationsApproval in-app notifications show real field values (e.g. the RCF ID) instead of raw {{…}} tokens, in custom text and templates.Approvers can see which record a notification is about.

6. Configuration Changes

ConfigurationDescriptionImpact
Multi-Factor Authentication (MFA)New organisation setting in Metadata Console → Organisation, off by default. Email OTP uses the SMTP config; Mobile (SMS) OTP needs a default SMS gateway in the workspace.Turn on per organisation to require an OTP at login (and on workspace switch with auth policy "Workspace").
ALLOW_ADMIN_SWITCH_PASSWORD (tenant variable)Default false.When true, Administrators must enter the workspace password (and OTP with MFA) when switching workspace.
MAX_LOGIN_ATTEMPTS, RESET_UNLOCK_EVERY, LOGIN_LOCK_DURATION_MINUTESLogin now reads MAX_LOGIN_ATTEMPTS live; automatic locks last RESET_UNLOCK_EVERY when auto-unlock is on, otherwise LOGIN_LOCK_DURATION_MINUTES (default 15).Check these values on the test tenant before testing lockout.
AZURE_BLOB_ACCOUNT_KEY, AZURE_BLOB_READ_SAS_TTL_HOURS (master)With the account key set, file URLs get per-file read-only access (default lifetime 8760 hours). Without it the old behaviour continues with a [SECURITY] warning in the logs.Run the URL migration (resignBlobUrls.js --apply) to rewrite already-saved file URLs.
RBAC menu seedNew routes: Task Scheduler task groups (View/Create/Edit/Delete) and the Workspace → Session Params submenu (a migration grants it to existing roles).Run the RBAC menu seeder and flush the Redis menu cache on the environment, otherwise these screens return 403.
Transaction Settings – Publish to EruditeNew parameter: Publish automatically (default) / Always ask / Don't publish.Set per feature that uses the Publish to Erudite node.
Chat rate limitsAll chat routes 400 requests/min per user (was 200); create meeting 20/min (was 10); join meeting 40/min (was 20).Normal call testing no longer hits "Too many requests".
Print templates – layoutTemplates saved or published from the designer are stamped with the paper-edge layout, so blocks print where they are drawn.Older templates keep their current print positions until re-saved in the designer.

7. API Changes

API NameTypeDescription
POST /public/users/loginChangedWhen the organisation has MFA on, a correct password returns { mfaRequired: true, challengeId, methods[], otpLength } instead of a session. Too many failed attempts return 423 with "Your account is locked … try again in N minute(s)".
POST /public/users/login/mfa/send-otp, POST /public/users/login/mfa/verify-otpNewSend the login OTP to the chosen method; verify it and return the normal login response. An expired or over-used challenge returns code MFA_CHALLENGE_EXPIRED.
POST /users/workspace-switch/verify-password, POST /users/workspace-switch/mfa/send-otp, POST /users/workspace-switch/mfa/verify-otpNewWorkspace switch: check the target workspace password (returns isValid, mfaRequired, challengeId, methods), then send and verify the OTP.
Forgot password / verify OTP / reset (public)ChangedAlways answers 200 "If an account exists…, an OTP has been sent"; an unknown account behaves like an expired OTP; 5 wrong OTPs invalidate it. Rate limits (per IP / per account): login 30 per 5 min / 10 per 15 min; forgot-password and resend-OTP 10 / 3 per 15 min; OTP verify and reset 20 per 15 min per IP.
PUT /tenant/tenantPage, GET /tenant/:tenantId/basicinfoChangedCarry the organisation's mfaEnabled setting.
GET /public/domain, file upload responsesChangedFile URLs carry a read-only access token for that one file (no container-wide token).
GET / PUT /master/features/:id/session-paramsNewRead / save a feature's session params and "find the user's record by" field ({ sessionParams, matchField }).
POST /session-params/previewNewPreview the session-param values a given login value would produce (read-only).
Login / refresh / workspace switch (access token)ChangedThe access token carries the user's sessionParams; Data Access Control rules using $$SESSION_PARAM:<key>$$ are resolved from it.
POST /master/feature-data/:featureId/data/search, export, POST /master/extraction/:featureIdChangedNew filter operators: in ("is any of", array value), greaterThanOrEqual, lessThanOrEqual — used by Column Filter. Column Filter pick lists use extraction facet counts.
POST /master/extraction/:featureIdChangedAccepts lookups[] (up to 20) so listing card values can come from another feature's fields.
GET /master/extraction/:featureId/fieldsChangedAlso lists fields inside role-restricted stepper steps.
POST /master/feature-data/:featureId/data/auto-id/previewChangedAccepts tableId and count for Auto Gen ID table columns and returns previewValues.
GET / POST /notification/scheduler/task-groups, PUT / DELETE /notification/scheduler/task-groups/:idNewTask Group CRUD (list includes taskCount). 409 for a duplicate name or deleting a group still used by a task.
POST /template-service/templates/print-templates/:id/generate-docxNewDownload a record's print document as Word.
POST /template-service/templates/print-templates/:id/generate-pdfChangedReturns the stored PDF when nothing that shapes the document has changed, instead of rendering again.
Feature record save / readChangedNested Child Rows tables store and return each row's child rows (under the table's Child Rows key).
Runtime dashboard / dashboards by roleChangedInactive dashboards are excluded.
POST /master/feature-data/:featureId/inter-service/record-operationsNew (internal)Scheduler-only endpoint for scheduled Update / Upsert record actions; user tokens get 401.
POST /internal/print-links (master), POST /internal/erudite/documents/publish (rbac)New (internal)Used by the Publish to Erudite workflow node to save the record's PDF and create the Erudite document.
