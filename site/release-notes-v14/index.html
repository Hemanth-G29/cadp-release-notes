2. Release Summary

This release of CADP Workspace Version 1.0.0 (14) focuses on platform performance and stability. Key highlights include optimized platform loading time, optimized feature design page loading time, and multiple bug fixes across the platform.

3. New Features

Feature ID Feature Name Description Impact
– Archive Protection – Feature & Module When you archive a feature or module, the system checks if any other features are using its fields in formulas, dropdowns, or lookups. If yes, a warning popup appears showing which fields are affected. You can either cancel the archive or click Force & Reset to clear those linked fields and proceed. Prevents other features from breaking silently when a feature or module is archived.
– Field Delete Protection in Builder When you delete a field from the builder and save, the system checks if that field is used in formulas, dropdowns, or lookups in other features. If yes, a popup appears letting you cancel or click Force & Reset to clear those links and save. Stops broken formulas and empty dropdowns from appearing in other features when a shared field is deleted.
– Cascading Formula Clear on Reset When a formula field is cleared by Force & Reset, any other formulas in the same feature that depend on it are also automatically cleared. This works across any chain — for example, if Formula C uses Formula B which uses the deleted Field A, all three are cleared together in one go. No partial or broken formulas are left behind after a reset — all dependent formulas in the chain are cleaned up automatically.
– Formula & Lookup Links Kept When Cloning When you clone a feature or module, all formula, dropdown, and lookup links to other features are copied over correctly. The cloned feature is also protected — if a referenced feature is later archived, the warning popup will appear for the clone too, just like the original. Cloned features work exactly like the original — no missing links or broken references after cloning.
