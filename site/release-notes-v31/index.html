2. Release Summary

This release of CADP Workspace Version 1.0.0 (31) delivers 35 bug fixes, 22 new features, and 32 enhancements across the platform. Highlights include Charts can show only their top N categories, filter on category totals, and use formula filters, Open Module / Open Feature shortcuts can be limited to one page, and New workspaces get the System notifications kit from the notification service. It also includes a required configuration change (see Configuration Changes) and API changes (see API Changes). Refer to the Known Issues section for current limitations.
