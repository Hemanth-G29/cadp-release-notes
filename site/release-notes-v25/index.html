2. Release Summary

This release of CADP Workspace Version 1.0.0 (25) delivers 0 bug fixes, 5 new features, and 16 enhancements across the platform. Highlights include Download PDF for user manuals (same pipeline as Release Notes), Download PDF restored (code was missing behind the two entries above), and Table rows obey their columns' rules: Required, allowed dates, length, pattern, email. Table rows obey their columns' rules: Required, allowed dates, length, pattern, email**Row checks (definition tables, runtime only).** "+" refuses the entry row, and saving an edited row refuses the edit, while a shown column breaks its own rule. The rules are Required (blank, whitespace, empty rich text or an empty lookup object), the date rules below, min/max length, pattern, and email format. One message names every problem, e.g. "Please fill: Corrective Actions, Target Date · Target Date: past dates are not allowed". Auto-ID, formula, read-only and hidden or condition-hidden columns are never demanded. An edit save skips the date rules, so a row saved earlier keeps its old dates.; **Allowed Dates for table date columns.** Columns → Column Settings shows an "Allowed Dates" card under Default Date: Disable past dates, Disable future dates, Disable weekends, Earliest date, Latest date. It is saved on the column (`basic.disablePastDates`, `disableFutureDates`, `disableWeekends`, `minDate`, `maxDate`) and rides the seed's existing `defaultDate` slot, so no seed change is needed. A Date field dragged into the table keeps its own picker settings (`advanced.datepicker.*`); those apply when the column has no Allowed Dates of its own.; **Date cell.** The table's date cell (shared by definition and transaction tables) sets `min`/`max`, so the browser calendar greys the out-of-range days. A date that still breaks a rule (typed by hand, or a weekend) is refused with a message.; **Required marker.** A definition-table header shows a red `*` after the label of every column "+" demands (`isUserRequiredColumn`: Required and filled by the user, so an auto-ID column gets none). It sits outside the truncating label so a narrow column never clips it, in the builder canvas and at runtime alike.; **Shared logic.** All of it lives in `helpers/tableRowChecks.ts`. Length and pattern are read through `buildOverlayFieldConfig`, the same lookup the table's text editors use.Required on a table column was never enforced when adding a row. The add path only asked "is any cell filled", and the auto-generated Task ID always is, so RCF's "Long Term Corrective action" took rows holding nothing but T00001. Table date columns had no allowed-date rules at all: the cell was a bare `<input type="date">`. The Submit-time "Check Required columns" toggle exists in code but is missing from the live component-properties seed, so it cannot be switched on.
User Manual: Download PDFThe Preview tab has a "Download PDF" button. It calls; `userManualApi.downloadPdf` (arraybuffer, 120s) and saves the server-rendered PDF under the; file name the server sends. Before downloading, it saves any unsaved Review & Customize; edits (`onBeforeDownload` → `persist("preview")`) so the PDF matches the preview. The; backend error message is decoded from the arraybuffer body. The HTML download and Print; buttons remain.
New chart type: FunnelAdded **Funnel** as a chart type, a twelfth tile in the Chart Type picker; (Chart Properties) of the generic **Charts** component. A funnel uses the same data; mapping as a pie: a **Stage Field**, plus a value (Count / Percentage / Sum / Average; or a value formula). New **Funnel Options**:; **Stage order:** largest first (default), smallest first (pyramid), data order, or; a custom comma/new-line list. A listed stage with no records shows as an empty 0; stage; unlisted stages follow at the bottom.; **Conversion %:** of the first stage (default), of the previous stage, or hidden.; A pyramid measures from its bottom (entry) stage.; **Stage labels:** inside / right / left / hidden.; **Gap** between stages (0–20 px).Requested chart type for stage-by-stage drop-off (e.g. RCF stages).
